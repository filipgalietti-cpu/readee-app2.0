# THE 25-RULE GOLDEN LESSON RUBRIC (grade every lesson against this)

Grade each rule pass / fail / na. Note the SURFACE for visual rules (desktop / mobile / both). Be honest and critical — the bar is "fantastic," not "acceptable."

## A. Structure & headings
1. Shape: intro → teach(1-2) → example → tip → (interactive fork) → practice-intro → MCQs.
2. Headings = 2-4 playful words naming the content. Example heading "Let's Try One"; practice-intro "Time to Practice!".

## B. On-screen text (the golden rule)
3. Screen ANCHORS the audio, never transcribes it. One idea per pill. (A full spoken sentence printed on screen = FAIL.)
4. Terseness: pill ≤5 words · question ≤4 · answer ≤5 · passage ≤16 words.
5. Use the audio's REAL words — no abstract summaries ("Story Elements").
6. One focal point per slide.

## C. Each slide type (shape)
7. Intro — frame it, then reveal key terms as pills, or a transformation visual. Greeting audio-only.
8. Teach — one concept per step as a short anchor, OR a table for a structured set. Story examples in the box.
9. Example ("Let's Try One") — framing → focal content (passage/word) → Q→A pairs (answer lights up) → closing.
10. Tip — one memorable trick: short anchor or flowing equation.
11. Practice-intro — "Your turn!" + a couple pills.
[FORK] Interactive "Your Turn" — skill-matched, NO giveaway, same-category plausible distractors, affirmation names WHY, encouragement nudges without revealing; bunny coach shows; match columns scrambled.

## D. Story box, tables, underlines, emphasis
12. Narrative/example text → italic STORY BOX, never a bare pill.
13. A structured SET of items → table rows, not prose.
14. Phonics/vocab: underline the focal chunk in the word (ai / un / bio).
15. The chunk/answer word lights up WHEN spoken; comprehension underlines the answer in the passage.

## E. Images
19. One image per slide: bright 2D cartoon, NO text/letters, matches the content, natural proportions, no eye-glints/slop; suppress when a table carries the slide. (JUDGE THE ACTUAL RENDERED IMAGE.)

## F. Pedagogy
20. Teaches the EXACT standard.
21. No word repeats across slides (teach word ≠ example word).
22. Q2 never contains Q1's answer.
23. Audio explains the pills on screen.
24. Every slide earns its screen time — no filler.

## G. Layout & presentation (CRITICAL — judge from the screenshots, both surfaces)
25. Balanced composition — NO floating-in-a-void / dead space. Heading + content read as one centered group; content fills its panel comfortably; nothing crammed or overflowing; NO black body text (violet/themed only); on mobile: pills/anchors sized right, fork columns fit the phone, image not too big/small, nothing cut off.

## NOT graded here (separate audio/timing pass): #16 timing-to-audio (Whisper), #18 audio pronunciation/SFX.
