# K.L.1 — Grammar Basics  (grade Kindergarten)

## [intro] heading: "Let's Learn Grammar Basics!"
  AUDIO: Grammar is the set of rules that helps us talk and write in a way that makes sense!
    SCREEN: Grammar: rules
  AUDIO: When we use good grammar, people understand us! And it's not hard at all.
    SCREEN: Good grammar: understood
  AUDIO: Let's learn some basic grammar rules!

## [teach] heading: "Words Have Jobs!"
  AUDIO: Did you know that words have different jobs? Some words name things — like 'cat' or 'ball.'
    SCREEN: Words have jobs
  AUDIO: These are called nouns! A noun names a person, place, or thing.
    SCREEN: Nouns name things
  AUDIO: Other words show action — like 'run,' 'jump,' or 'eat.' These are verbs!
    SCREEN: Verbs show action
  AUDIO: Nouns and verbs work together to make sentences! Like: The cat runs.
    SCREEN: The cat runs

## [example] heading: "Let's Find Nouns and Verbs!"
  AUDIO: Look at this sentence: The dog jumps.
    SCREEN: The dog jumps.
  AUDIO: What's the noun? The dog! Dog is a thing, so it's a noun!
    SCREEN: What's the noun? / The dog!
  AUDIO: What's the verb? Jumps! Jumping is an action, so it's a verb!
    SCREEN: What's the verb? / Jumps!

## [tip] heading: "A Helpful Trick!"
  AUDIO: To find a noun, ask: Can I touch it or see it? If yes, it's probably a noun!
    SCREEN: Find noun? / Touch or see?
  AUDIO: To find a verb, ask: Can I do it? If yes, it's a verb!
    SCREEN: Find verb? / Can I do it?
  AUDIO: You're a grammar detective!
