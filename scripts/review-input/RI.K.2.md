# RI.K.2 — Finding the Main Topic  (grade Kindergarten)

## [intro] heading: "Let's Find the Main Topic!"
  AUDIO: When we read a fact book, it's usually all about one big thing. That big thing is called the main topic!
    SCREEN: Main topic = one big thing
  AUDIO: Like a book about dogs — the main topic is dogs! Everything in it tells us about dogs.
    SCREEN: Example: book about dogs
  AUDIO: Let's learn how to find the main topic in any fact book!

## [teach] heading: "What Is the Main Topic?"
  AUDIO: The main topic is what the whole book is mostly about.
    SCREEN: Main topic: what book about
  AUDIO: If a book talks about where fish live, what fish eat, and how fish swim — what's the main topic?
    SCREEN: What's the main topic?
  AUDIO: Fish! All the facts are about fish. So the main topic is fish!
    SCREEN: Main topic: Fish!

## [example] heading: "Let's Try One Together!"
  AUDIO: Listen to these facts and figure out the main topic!
  AUDIO: Apples grow on trees. Apples can be red, green, or yellow. Apples taste sweet!
    SCREEN: Apples grow on trees. Apples can be red, green, or yellow. Apples taste sweet!
  AUDIO: What are all these facts about? Apples! The main topic is apples!
    SCREEN: What about? / Apples!

## [tip] heading: "A Helpful Trick!"
  AUDIO: Here's an easy trick. Ask yourself: What is this book mostly about?
    SCREEN: What is it about?
  AUDIO: Look at what keeps coming up again and again. That thing is the main topic!
    SCREEN: Main topic: what comes up
  AUDIO: It's like finding the star of the show!
    SCREEN: Star of the show!
