# L.1.1 — Grammar Power  (grade 1st Grade)

## [intro] heading: "Word Jobs"
  AUDIO: Every word in a sentence has a job.
    SCREEN: Every word has a job
  AUDIO: Some words name things. Some show action. Some describe.
    SCREEN: Name. Do. Describe.
  AUDIO: Knowing the jobs helps us talk and write clearly!
    SCREEN: Talk and write clearly

## [teach] heading: "Nouns Name Things"
  AUDIO: A noun names a person, place, or thing.
    SCREEN: Noun: person / Place / Thing
  AUDIO: Dog. Tree. School. Mom. All nouns!
    SCREEN: Dog / Tree / School / Mom
  AUDIO: If you can point to it, it is usually a noun.
    SCREEN: Point to it? Noun.

## [teach] heading: "Verbs Show Action"
  AUDIO: A verb shows action. What someone is doing.
    SCREEN: Verb shows action
  AUDIO: Run. Jump. Clap. Eat. All verbs!
    SCREEN: Verbs
  AUDIO: Every sentence needs a verb to tell what is happening.
    SCREEN: Sentence needs verb

## [example] heading: "Let's Try One"
  AUDIO: Let's try one together. Here's a word.
  AUDIO: Here is the word: ball.
    SCREEN: ball
  AUDIO: Can you point to a ball? Yes! You can hold it and point to it.
    SCREEN: Can you point to it? / Yes!
  AUDIO: So what job does it do? It names a thing, so it is a noun!
    SCREEN: What job is it? / A noun!
  AUDIO: So ball is a noun. It names a thing. You spotted the job!

## [tip] heading: "Spot the Jobs"
  AUDIO: Here is a helpful trick.
  AUDIO: Ask: what names a thing? That is the noun. What shows action? That is the verb!
    SCREEN: Names vs. Action
  AUDIO: Now you are ready to spot grammar jobs!
