  AUDIO: Each subject has its own set — science, history, math.

## [teach] heading: "Context Clues Again"
  AUDIO: Context clues still work. The words around a big word give hints.
    SCREEN: Context clues give hints

## [teach] heading: "Word Parts Help"
  AUDIO: Break the word into prefix, root, suffix.
    SCREEN: Prefix / Root / Suffix
  AUDIO: Photograph has photo (light) + graph (writing). A writing with light!
    SCREEN: Photograph: light writing

## [example] heading: "Let's Try One"
  AUDIO: Let's try one together. Here's a fancy word.
  AUDIO: Here is the word: habitat.
    SCREEN: habitat
  AUDIO: Which subject uses it? Science!
    SCREEN: Which subject? / Science.
  AUDIO: What does it mean? An animal's home.
    SCREEN: What does it mean? / An animal's home.
  AUDIO: Habitat means an animal's home. You cracked an academic word!
