# RI.4.10 — Reading Big Facts  (grade 4th Grade)

## [intro] heading: "Long Nonfiction"
  AUDIO: Fourth graders read long nonfiction articles, packed with lots of facts.
    SCREEN: Long fact articles
  AUDIO: A long article can feel like a lot. But every section has one main idea holding it together.
    SCREEN: Each section: one main idea
  AUDIO: All the other sentences are supporting details. They explain or prove that main idea.
    SCREEN: Details support the main idea

## [teach] heading: "Main Idea vs Detail"
  AUDIO: The main idea is the one big point the whole paragraph is about.
    SCREEN: Main idea = the big point
  AUDIO: Supporting details are the small facts, like numbers or examples, that back it up.
    SCREEN: Details = small backup facts

## [teach] heading: "Read the Whole Section"
  AUDIO: In a long text, read the whole section before you decide the main idea.
    SCREEN: Read the whole section first
  AUDIO: Then ask: what one idea do all these details point to?
    SCREEN: Ask: what do details point to?

## [example] heading: "Let's Try One"
  AUDIO: Let's try one together. Here is a section from a nonfiction article.
  AUDIO: Volcanoes can change the land fast. Lava buries forests. Ash covers nearby towns. New rock builds taller mountains.
    SCREEN: Volcanoes change the land fast. Lava buries forests. Ash covers towns. New rock builds mountains.
  AUDIO: First, the small details: lava, ash, and new rock. These are the proof.
    SCREEN: Details? / Lava, ash, new rock
  AUDIO: Now, what one idea do they all point to? Volcanoes change the land.
    SCREEN: Main idea? / Volcanoes change the land
  AUDIO: See? The details all proved one big main idea. You found it!

## [tip] heading: "The Glue Trick"
  AUDIO: Here's a trick. The main idea is the glue, and details are what it holds together.
    SCREEN: Main idea = the glue
  AUDIO: If a sentence is just one small fact, it's a detail, not the main idea.
    SCREEN: One small fact = detail
