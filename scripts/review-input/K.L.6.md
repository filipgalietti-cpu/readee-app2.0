# K.L.6 — Using New Words  (grade Kindergarten)

  AUDIO: You learn new words all the time! But the best part is using them!

## [teach] heading: "How to Use New Words"
  AUDIO: When you learn a new word, try to use it right away! Say it in a sentence!
    SCREEN: Use new words!
  AUDIO: Like if you learn the word 'enormous,' try saying: That building is enormous!
    SCREEN: enormous!
  AUDIO: The more you use a word, the better you remember it!
    SCREEN: Use it → Remember it!
  AUDIO: Pretty soon, new words become YOUR words!

## [example] heading: "Let's Use a New Word!"
  AUDIO: Here's a new word: 'delighted.' It means really, really happy!
    SCREEN: Delighted = really happy
  AUDIO: Can you use it in a sentence? How about: I was delighted to see my friend!
    SCREEN: delighted!
  AUDIO: See? You just used a brand new word! You're a vocabulary superstar!

## [tip] heading: "A Helpful Trick!"
  AUDIO: Every time you learn a new word, use it three times that day!
    SCREEN: Use it three times!
  AUDIO: Use it talking to a friend, use it in a sentence you write, and use it at home!
    SCREEN: Talk / Write / Home
  AUDIO: Three times and that word is yours forever!
    SCREEN: Yours forever!
