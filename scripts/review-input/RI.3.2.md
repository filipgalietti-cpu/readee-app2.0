# RI.3.2 — Main Idea and Key Details  (grade 3rd Grade)

## [intro] heading: "Main Idea = Big Idea"
  AUDIO: The main idea is what the text is mostly about.
    SCREEN: Main idea: mostly about
  AUDIO: Key details are facts that support the main idea.
    SCREEN: Key details: support idea

## [teach] heading: "Dogs as Helpers"
  AUDIO: Imagine a text about dogs as helpers.
  AUDIO: Details: guide dogs. Therapy dogs. Search and rescue dogs.
    SCREEN: Details
  AUDIO: Main idea: dogs help people in many ways.
    SCREEN: Main idea: dogs help

## [example] heading: "Summary Sentences"
  AUDIO: A good summary is one sentence on the main idea plus two or three key details.
    SCREEN: Summary: main idea + details

## [tip] heading: "Summarize It"
  AUDIO: Here is a helpful trick.
  AUDIO: After reading, write one sentence: this text is about blank because blank.
    SCREEN: Write one sentence
  AUDIO: Now you are ready to find main ideas!
