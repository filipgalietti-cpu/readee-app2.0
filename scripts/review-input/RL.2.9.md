# RL.2.9 — Same Story, Different Versions  (grade 2nd Grade)

  AUDIO: The same story can be told in different ways.
    SCREEN: Same story, different ways
  AUDIO: Different authors. Different pictures. Sometimes different endings!
    SCREEN: Different versions
  AUDIO: Let us see what stays the same.

## [teach] heading: "Cinderella Everywhere"
  AUDIO: Cinderella has been told all over the world.
    SCREEN: Cinderella worldwide
  AUDIO: Some versions have a fairy godmother. Some have a magic fish!
    SCREEN: Fairy or fish
  AUDIO: The main story is the same. The details change.
    SCREEN: Same story, new details

## [example] heading: "Compare Two"
  AUDIO: What is the same? The main characters. The big problem.
    SCREEN: Same: characters, problem
  AUDIO: What is different? The setting. The small parts. The ending sometimes.
    SCREEN: Different: setting, details, ending
  AUDIO: Both ways can be fun in their own way!
    SCREEN: Both can be fun

## [tip] heading: "Same + Different"
  AUDIO: Here is a helpful trick.
  AUDIO: Make two lists. Same on one, different on the other.
    SCREEN: Make two lists
  AUDIO: Now you are ready to compare different story versions!
