## [tip] heading: "Cover and Discover"
  AUDIO: Here is a helpful trick.
  AUDIO: Cover the prefix and suffix. What is left? That is the root!
    SCREEN: Cover, find root
  AUDIO: Let's try it with the word 'unhappy.' If we cover 'un' and 'y,' we find the root word 'happy'!
    SCREEN: unhappy: root happy
  AUDIO: Now you are ready to use root words!
