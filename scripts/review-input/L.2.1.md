# L.2.1 — Sentence Skills  (grade 2nd Grade)

## [intro] heading: "Verbs That Break the Rule"
  AUDIO: Most verbs add E-D to talk about yesterday. Walk becomes walked!
    SCREEN: Add -ed for yesterday
  AUDIO: But some verbs are tricky. They change into a whole new word!
    SCREEN: Some verbs change
  AUDIO: We call these irregular verbs. Let us learn them!
    SCREEN: Irregular verbs

## [teach] heading: "Today and Yesterday"
  AUDIO: Today I run. But yesterday I did not say runned!
    SCREEN: Today: run / Not runned!
  AUDIO: Yesterday I ran. Run changes into ran!
    SCREEN: Yesterday? / ran

## [teach] heading: "More Tricky Verbs"
  AUDIO: Eat becomes ate. Go becomes went. See becomes saw.
    SCREEN: ate, went, saw
  AUDIO: They never add E-D. The whole word switches!
    SCREEN: No -ed for these

## [example] heading: "Let's Try One"
  AUDIO: Let us try one together. Here is a sentence about today.
  AUDIO: Today the birds fly south.
    SCREEN: Today the birds fly south.
  AUDIO: What is the verb? Fly!
    SCREEN: What is the verb? / fly
  AUDIO: Now make it yesterday. Fly becomes flew!
    SCREEN: Yesterday? / flew
  AUDIO: Yesterday the birds flew south. We did not say flyed!
    SCREEN: Birds flew, not flyed!

## [tip] heading: "Say It Out Loud"
  AUDIO: Here is a trick. Say it out loud with the word yesterday.
    SCREEN: Add the word yesterday
  AUDIO: Yesterday I goed? That sounds wrong. Yesterday I went? That sounds right!
    SCREEN: goed or went? / went sounds right
